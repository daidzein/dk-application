# Sales Dashboard – Dua Kelinci Build Test

A single-file web app (no installs, no internet, no API keys) that shows
net sales by region and brand, flags the 5 weakest outlets, and writes a
one-paragraph Indonesian summary a sales manager can paste into Telegram.

## How to run

1. Keep `index.html` and `sales.csv` in the same folder.
2. Double-click `index.html` (any modern browser).
3. Click "Choose file" and select `sales.csv`
   (or drag it in, or paste the CSV text and click "Load pasted CSV").

Everything runs locally in the browser; no data leaves the machine.

## What it shows

- **Overview:** net sales, invoice count, outlet count, returns, period.
- **Net sales by region:** bar chart.
- **Region x brand:** table with heat shading and totals.
- **5 weakest outlets:** with a switch between two definitions (below).
- **Telegram summary:** plain text, one paragraph, with a Copy button.
- **Data cleaning notes:** counts of everything the app fixed or removed.

## Assumptions and decisions

- **Metric:** `net_sales_idr` (after discount) is used everywhere.
- **Outlets are identified by `outlet_id`, not name.** Several different
  outlets share a name (for example "Toko Anugerah" in different cities),
  so grouping by name would merge unrelated outlets.
- **Weakest outlets, two definitions:**
  1. *Lowest total net sales* (default): simple and easy to explain.
  2. *Lowest vs. the median of the same outlet type:* fairer, because a
     warung is not expected to sell like a wholesaler (Grosir).
  Outlets with no sales in the period do not appear in the data, so they
  cannot be ranked.
- **Returns:** rows with negative quantity (invoice prefix `RTR`) stay in
  net sales so totals are correct, but are not counted as invoices.

## Data cleaning

| Issue found | What the app does |
|---|---|
| Region spelling and case (`Jabar`, `JAWA BARAT`, `JABODETABEK`) | Normalized to one spelling |
| Stray spaces (e.g. `Grosir Berkah `) | Trimmed |
| Blank `salesman` | Labelled "Unknown", kept in totals |
| Exact duplicate rows | Removed by default (checkbox to keep); affected invoices are listed in the notes |
| Return rows | Kept in sales, excluded from invoice count |

## Limits and what I would do next

- Only September–October 2026 is available, so there is no trend or
  seasonality view.
- "Weak" is based on sales volume only; it does not account for outlet
  size, distance or visit frequency, which the data does not contain.
- The summary text is template-based (deterministic), not generated by a
  language model, so it is fast and gives the same result every time.
- Next steps: month-over-month comparison, per-salesman view, export to
  CSV/Excel, and a scheduled daily digest to Telegram.
